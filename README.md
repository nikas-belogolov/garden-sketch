# Garden Sketch

A modern, interactive garden planning application built with Next.js and Konva.

## Features

- 🌿 **Interactive Canvas**: Infinite canvas for sketching your dream garden layout.
- 🖱️ **Drag & Drop**: Easily add plants, geometric shapes, and garden furniture.
- 📐 **Precision Tools**: Measurement units (Metric/Imperial), grid snapping, and scaling.
- 🤝 **Real-time Collaboration**: Built with Yjs for collaborative editing capabilities.
- 🎨 **Rich UI**: Clean and responsive interface using Tailwind CSS and Shadcn UI.

## Tech Stack

- **Framework**: [Next.js](https://nextjs.org/)
- **Canvas Library**: [React Konva](https://konvajs.org/docs/react/index.html)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Components**: [Shadcn UI](https://ui.shadcn.com/)
- **State Management**: [Jotai](https://jotai.org/) & [Yjs](https://github.com/yjs/yjs)

## Getting Started

1. **Install dependencies:**

   ```bash
   pnpm install
   ```

2. **Run the development server:**

   ```bash
   pnpm dev
   ```

3. **Open the app:**
   Visit [http://localhost:3000](http://localhost:3000) in your browser.
